## 保留的问题 6：扫描页边界判断

七份样本第 6 页的可见文字在版心内，但整张扫描位图外框覆盖整页。当前工具按图片外框提示横向越界，而测试预期按可见内容判断，所以这 7 项继续记录为失败。本轮未加入 OCR 或可见墨迹边界识别，也未改变验收标准。

## 能力边界

- 页眉及行号识别依赖可辨认的文本和几何规律；不能核验整篇页边距是否相对官方模板被统一修改，不检查上下边距。
- 新增文献分条支持本轮 ICLR、ICML 及 NeurIPS 的 plainnat 样式。要求可识别的作者头与由逗号或句点分隔、以句点结束的末尾年份；不声称覆盖任意文献样式。未知尾部内容保守标记未检查。NeurIPS 的 plainnat 是本轮选择，并非声称会议只允许此样式。
- URL 断行去片段依赖 Annotation 完整地址与文字坐标的对应证据；没有证据时不盲目拼接下一行正文，人工核对仍有必要。
- 字体检查验证非空嵌入流，不验证字体程序本身是否完整可用。
- 网络用模拟 DNS/HTTP 响应验证 404、私网阻止、重定向和固定公网 IP 等行为，本轮没有真实访问样本中的内网或公网地址，不能据此证明网站当前可访问。
- 实验数字一致性、方法／数学符号一致性、纯姓名语义识别、引用真实性、投稿 Track 和系统状态等仍需人工或外部工具。Paper-BibChecker 继续按项目设计独立使用，不将未集成列为缺陷。

## 复现方法

使用已安装本项目依赖的 Python 环境。当前测试环境为 Python 3.10、PyMuPDF 1.28.2；原 PDF 使用 TeX Live 2025 构建。下面的复测不重建七份 PDF：

```bash
python -m autocheck.cli "test_pdf/acl(1).pdf" --disable_link_check --lang en
python -m autocheck.cli "test_tex copy/_submission_check/cvpr/baseline.pdf" --disable_link_check --lang en
python -m unittest discover -s tests -v
python "test_tex copy/_submission_check/verify_samples.py"
python "test_tex copy/_submission_check/write_report.py"
```

`expected_results.json` 包含每项预期、实际结果、原始结构化报告、修复前后对照及哈希。复测脚本、正常对照、变体、原始日志、此前渲染图及修复前快照留在副本工作区；该目录和 `tests/` 遵循当前忽略规则，提交测试 PDF 不会自动提交这些本地材料。
