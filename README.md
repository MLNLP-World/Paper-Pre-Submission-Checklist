## 项目特点

- **客观明确**：每个检查项都能用"是"或"否"回答，不留模糊地带。
- **便于修改**：发现问题后，能快速定位到具体的章节、图表或文件。
- **覆盖完整**：覆盖论文正文、附录、补充材料、最终 PDF 和投稿系统。
- **快速实用**：临近截稿时，可以直接跳到文末的快速检查。
- **脚本检查**：附带自动化检查脚本，机器能查的项一键扫描，剩下的交给清单逐项核对。

## 使用方式

1. 投稿前，逐项过一遍[完整检查清单](#完整检查清单)；
2. 每次修改论文后，重点复查"[全文交叉检查](#全文交叉检查)"；
3. 上传论文后，完成"[投稿材料与最终上传检查](#投稿材料与最终上传检查)"；
4. 时间实在不够，至少完成文末的"[快速检查](#快速检查)"。
5. 本项目包含[自动化检查脚本](#自动化检查工具)，能够快速验证一些机器可验证项目。

## 完整检查清单

### 正文内容检查

#### 1. 标题与摘要

- [ ] 标题中的方法名称与正文中的拼写和大小写一致。
- [ ] 摘要中首次出现的缩写均已定义。
- [ ] 摘要中的数据集、模型和指标名称与正文一致。
- [ ] 摘要中的实验数字与正文结果一致。
- [ ] 摘要中的性能提升数值计算正确。
- [ ] 摘要字数符合投稿要求。

#### 2. 介绍

- [ ] 方法名称与标题、摘要及方法部分一致。
- [ ] 缩写均在首次出现时定义。
- [ ] 贡献列表的编号连续，没有重复或缺失。
- [ ] 介绍中的实验数字与实验部分一致。
- [ ] 图表、章节和文献引用编号正确。
- [ ] 没有残留旧版本的方法名或实验结果。

#### 3. 方法

- [ ] 每个数学符号均在首次出现时定义。
- [ ] 同一数学符号在全文中的含义保持唯一且一致。
- [ ] 公式、正文、算法和图片中的变量写法一致。
- [ ] 所有公式编号和正文引用正确。
- [ ] 方法图中的模块名称与正文一致。

#### 4. 实验设置与结果

- [ ] 数据集、模型、评价指标及实验设置在正文与附录中一致。
- [ ] 表格中的最佳（如粗体）、次优（如底纹或下划线）结果标注无误，且明确说明了指标的优劣方向（"↑"越高越好或"↓"越低越好）。
- [ ] 表格中的平均值和性能提升计算正确。
- [ ] 正文、表格与附录中重复出现的实验结果一致。

#### 5. 相关工作与参考文献

- [ ] 引用论文的标题、作者、年份和发表场所准确，无幻觉引用。
- [ ] arXiv 论文没有被错误标记为正式发表论文。
- [ ] 使用的数据集、模型和工具包均已引用。
- [ ] 同一篇论文没有在参考文献中重复出现。
- [ ] 正文中的作者姓名和年份与参考文献一致。
- [ ] URL、DOI 和 arXiv 链接可以正常访问。

#### 6. 结论、附录与补充材料

- [ ] 结论中的实验数字与正文一致。
- [ ] 结论中没有出现正文未报告的新结果。
- [ ] 所有附录均已在正文中引用。
- [ ] 正文与附录中的数字、超参数和设置一致。
- [ ] 附录和补充材料中的图表、公式及章节编号正确。
- [ ] 补充材料可以正常打开，且内容为最终版本。

#### 7. 全文图表与图片

- [ ] 数据图和结构图使用矢量格式，位图清晰且无变形、裁切。
- [ ] 图中文字在论文 100% 缩放下清晰可读。
- [ ] 坐标轴、单位、图例和子图编号完整、正确。
- [ ] 图表中的数据及结果标注与正文一致。
- [ ] 所有图表均未超出页面，并已在正文中正确引用。

### 全文交叉检查

#### 8. 实验结果一致性

- [ ] 摘要中的数字与主结果表一致。
- [ ] 介绍中的数字与实验部分一致。
- [ ] 结论中的数字与正文一致。
- [ ] 同一结果在不同表格中保持一致。
- [ ] 正文与附录中的重复结果保持一致。
- [ ] 所有平均值、差值和提升比例计算正确。
- [ ] 正文中的所有数据均有图表来源。

#### 9. 术语与符号一致性

- [ ] 方法名称的拼写和大小写全文一致。
- [ ] 数据集、模型和 Baseline 名称全文一致。
- [ ] 评价指标名称全文一致。
- [ ] 同一个概念没有使用多个不同名称。
- [ ] 同一个缩写没有被重复定义。
- [ ] 数学符号、上下标、粗体和斜体格式一致。

#### 10. 引用与交叉引用

- [ ] PDF 中没有出现 `[?]` 或 `??`。
- [ ] 没有出现 "Figure ?" "Table ?" "Equation ?" 等未解析引用。
- [ ] 所有正文引用的文献均出现在参考文献列表中。
- [ ] 所有图、表、公式、章节和附录均被正确引用。
- [ ] 图表、公式、章节和附录编号连续、无重复。
- [ ] PDF 中的内部链接和外部链接可以正常打开。
- [ ] 括号引用与行内引用区分正确（错误示范：As shown in (Smith et al., 2020)；正确示范：As shown in Smith et al. (2020)）。

#### 11. 拼写与残留内容

- [ ] 全文没有明显的拼写错误或重复单词。
- [ ] 方法名、数据集名和模型名没有拼写错误。
- [ ] 全文没有 `TODO`、`TBD`、`XXX` 或 `FIXME`。
- [ ] 全文没有作者批注、高亮、删除线或修订痕迹。
- [ ] 全文没有残留旧方法名、旧实验结果或模板示例文字。
- [ ] 没有 LaTeX 命令直接显示在 PDF 中。
- [ ] 没有未闭合的括号、引号或异常标点。

#### 12. PDF 渲染与版面

- [ ] PDF 没有空白页、缺页或重复页面。
- [ ] 图表、公式和文字没有超出页边距。
- [ ] 图片没有变形、裁切或显示失败。
- [ ] 页眉、页脚和页码符合模板要求。
- [ ] PDF 中的字体已正确嵌入。
- [ ] PDF 可以正常搜索和复制文字。

### 投稿材料与最终上传检查

#### 13. 投稿规范

- [ ] 使用了目标会议或期刊要求的最终模板。
- [ ] 页数、字体、页边距和文件大小符合投稿要求。
- [ ] 参考文献和附录的页数计算方式符合要求。
- [ ] 已包含要求的 Checklist、Limitations 或 Ethics Statement。
- [ ] 主论文和补充材料的文件格式符合要求。

#### 14. 匿名信息（如要求）

- [ ] PDF 正文中没有作者姓名、单位、邮箱和致谢信息。
- [ ] PDF 元数据中没有作者姓名。
- [ ] 文件名中没有作者或单位信息。
- [ ] 补充材料中没有泄露作者身份的信息。
- [ ] 图片、截图和代码片段中没有用户名或本地路径。
- [ ] GitHub、云盘和项目主页链接没有泄露作者身份。
- [ ] 自引表述符合目标会议的匿名要求。

#### 15. 投稿文件与系统信息

- [ ] 上传的主论文和补充材料均为最终版本。
- [ ] 投稿系统中的标题和摘要与最终 PDF 一致。
- [ ] 作者姓名、顺序、邮箱和单位正确。
- [ ] 关键词、研究领域和投稿 Track 选择正确。
- [ ] 主论文与补充材料上传到了正确位置。
- [ ] 没有误上传旧版本或带批注版本。

#### 16. 上传后最终确认

- [ ] 已从投稿系统重新下载并检查主论文。
- [ ] 下载后的 PDF 页数正确，图表和公式显示正常。
- [ ] 补充材料已经成功上传并可以正常打开。
- [ ] 投稿状态显示为 Submitted 或 Submission Complete。
- [ ] 所有作者均已确认最终版本。
- [ ] 已保存最终文件和投稿确认信息。

## 快速检查

时间临近截稿时，至少把下面这几项过一遍。

#### 1. 内容检查

- [ ] 标题、摘要及正文中的方法名称全文统一。
- [ ] 摘要、正文、表格和结论中的实验数字一致。
- [ ] 公式、符号及图表编号正确，且均已在正文中引用。
- [ ] 参考文献真实存在，且作者、标题、年份和发表场所正确。
- [ ] PDF 正文中没有残留的 `[?]`、`??`、`TODO`、`FIXME` 或作者批注。

#### 2. 匿名性检查

- [ ] 正文、致谢、脚注及页眉均未包含作者姓名或机构信息。
- [ ] 补充材料、代码压缩包以及 PDF 文件属性（元数据）中没有泄露作者信息。
- [ ] 代码或项目链接使用的是匿名链接（如 Anonymous GitHub 等）。

#### 3. 排版与文件验证

- [ ] 使用目标会议/期刊要求的最新版模板（注意单双栏、字体、页码）。
- [ ] 论文总页数（以及正文页数）及文件大小未超出投稿系统限制。
- [ ] 所有图表均清晰，没有裁切、变形或超出页面。
- [ ] PDF 及补充材料没有泄露作者身份。
- [ ] 主论文和补充材料均为最终版本，且可以正常打开。

#### 4. 投稿确认

- [ ] 投稿系统中的标题、摘要、作者顺序和上传文件正确。
- [ ] 主论文和补充材料均为最新版本，且下载后能在不同阅读器中正常打开。

## 自动化检查工具

手工对照清单难免有疏漏，项目附带了一个基于 Python 的轻量级检查脚本，可以先把机器能查的项快速过一遍。

> **注意**：自动化工具只是人工检查的辅助，替代不了语义和逻辑层面的审阅，请配合上面的清单一起使用。

> **文字提取限制**：本工具不做 OCR（图片文字识别）。如果某页提取不到可用文字，报告会列出页码并标记"未检查"，提示相关文字检查无法完成，且不会显示 `All Clear!`，其余页面和元数据、格式检查不受影响。即使页面能提取部分文字，图片中的文字也仍需人工复核。

### 安装

可以使用[在线 Colab](https://colab.research.google.com/github/MLNLP-World/Paper-Pre-Submission-Checklist/blob/main/autocheck.ipynb) 运行，也可以在本地安装：

**方式一：克隆仓库后本地安装**

```bash
# clone
git clone https://github.com/MLNLP-World/Paper-Pre-Submission-Checklist.git

cd Paper-Submission-Checklist/

# install locally (editable mode)
pip install -e .
```

**方式二：直接从 GitHub 安装**

```bash
pip install git+https://github.com/MLNLP-World/Paper-Pre-Submission-Checklist.git
```

### 基本用法

检查单个 PDF 文件：

```bash
autocheck your_paper.pdf
```

递归检查整个文件夹下的所有 PDF：

```bash
autocheck ./paper_folder/
```

### 常用选项

切换报告语言（支持 `zh` 中文 / `en` 英文，默认中文）：

```bash
autocheck your_paper.pdf --lang en
```

跳过耗时的网络死链检查（仍执行离线参考文献去重和匿名链接检查）：

```bash
autocheck your_paper.pdf --disable_link_check
```

按目标会议要求配置页数限制（如单盲/双盲页数上限）：

```bash
autocheck your_paper.pdf --max_pages 8
```

调整图片分辨率阈值，或手动指定固定页边距（默认自动推断版心）：

```bash
autocheck your_paper.pdf --min_dpi 200 --margin_pt 36
```

批量检查时使用多进程加速：

```bash
autocheck ./paper_folder/ --num_workers 4
```

### 参数一览

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--lang {zh,en}` | 报告输出语言 | `zh` |
| `--disable_link_check` | 仅禁用 URL 网络死链检查，保留离线文献去重和匿名链接检查 | 网络检查默认启用 |
| `--max_pages N` | 最大页数限制 | 默认不检查 |
| `--min_dpi N` | 图片最低分辨率阈值 (DPI) | `150` |
| `--margin_pt N` | 页边距溢出检查的固定版心内缩值 (pt) | 默认自动推断 |
| `--num_workers N` | 并行处理的工作进程数 | `1` |

**命令退出码**：`0` 表示检查正常执行（论文是否有错误、警告或未检查内容，以报告为准）；`1` 表示至少一个 PDF 读取或检查失败；`2` 表示输入无效（如路径不存在、指定文件不是 PDF、指定目录没有 PDF）或命令行参数错误。批量处理时遇到无效输入或损坏文件，其余有效文件仍会正常检查，最终返回非零退出码；输入无效和 PDF 处理失败同时存在时返回 `2`。

### 目前支持的自动化检查功能

**1. 文件属性与排版**

* **文件大小**：超过 10 MB 时提示。
* **页数**：通过 `--max_pages` 设置上限，超限报错；默认不检查。
* **空白页**：检测无文字、无位图、无矢量图的页面。
* **字体嵌入**：检查是否存在未嵌入的字体；未嵌入的标准字体（Times、Helvetica 等 Base-14）降级为警告。
* **图片分辨率**：低于阈值（默认 150 DPI，可用 `--min_dpi` 调整）的位图提示可能模糊。
* **页边距溢出**：自动推断单/双栏版心，检查文字和图片是否横向越界，自动排除页码、审稿行号和页眉；也可用 `--margin_pt` 指定固定边距。仅检查横向，上下边距及整体模板改动需人工核对。

**2. 匿名性**

* **元数据**：Author 字段含疑似真实姓名时报错（`Anonymous` 等占位值除外）；Creator、Producer 残留本地编译路径（可能含电脑用户名）时提示；检测到 Word 编译时建议改用 LaTeX。
* **首页内容**：检测首页的机构关键词（University、Institute 等）和邮箱地址。
* **致谢**：出现 Acknowledgments 时提示核对匿名要求。
* **链接**：正文或注释中出现 GitHub、网盘、个人主页等链接时，提示替换为匿名链接（如 Anonymous GitHub）。此项为纯离线检查。

**3. 内容与引用**

* **未解析引用与草稿标记**：`[?]`、`??`、`Figure ?` 等未解析引用，以及 `TODO`、`FIXME`、`TBD`、`XXX` 等草稿标记。
* **低级错误**：连续重复单词（如 `the the`）、连续或孤立的异常标点、小写的图表引用（应为 `Figure 3`、`Table 2`）、括号数量不匹配。
* **图表跳号**：正文提及的 Figure、Table 编号存在缺号时提示。

**4. 外部链接与参考文献**

* **死链检测**：通过 HTTP 请求检查链接和 DOI 的可访问性，404/410 报为死链，其他异常状态提示人工核对。仅访问公网 80/443 端口，被安全策略阻止的链接标记为"未检查"。可用 `--disable_link_check` 关闭网络检查。
* **重复文献**：结合 PDF 的栏位、悬挂缩进和作者／年份信息分条，支持编号式及常见的无编号参考文献；通过条目文本相似度检测重复，题名完全相同时直接报错。部分内容无法分条时，继续检查已识别条目，同时标记"未检查"并提示相关页码；不会将部分检查当作全部通过。扫描页或复杂排版仍需人工复核。

### 触发 Warning / Error 的条件一览

| 检查项 | Warning 触发条件 | Error 触发条件 |
| --- | --- | --- |
| 文件大小 | 超过 10 MB | — |
| 页数 | — | 指定 `--max_pages` 且页数超限 |
| 空白页 | — | 某页无文字、位图和矢量图 |
| 字体嵌入 | 未嵌入字体属于 Base-14 标准字体 | 存在未嵌入的非标准字体 |
| 图片分辨率 | DPI 低于阈值（默认 150） | — |
| 页边距溢出 | 文字或图片横向越出版心 | — |
| 元数据作者 | — | Author 非空且非匿名占位值 |
| 元数据本地路径 | Creator/Producer 含本地绝对路径 | — |
| 编译工具 | Creator 为 Word | — |
| 首页机构/邮箱 | 首页出现机构关键词或邮箱 | — |
| 致谢 | 出现 Acknowledgments 部分 | — |
| 身份泄露链接 | 出现 GitHub、网盘、个人主页等链接 | — |
| 未解析引用 | — | 出现 `[?]`、`??`、`Figure ?` 等 |
| 草稿标记 | — | 出现 `TODO`、`FIXME`、`TBD`、`XXX` |
| 重复单词 | 出现连续重复单词（如 `the the`） | — |
| 异常标点 | 出现连续重复或孤立的标点 | — |
| 图表引用大小写 | 出现小写的 `figure 3`、`table 2` 等 | — |
| 括号平衡 | 括号开闭数量不匹配 | — |
| 图表跳号 | Figure/Table 编号存在缺号 | — |
| 死链 | 链接无法自动确认（403、超时等） | 链接返回 404/410 |
| 重复文献 | 条目文本相似度较高 | 两条文献题名完全相同 |

> 除 Warning 和 Error 外，报告中还可能出现"未检查"：页面提取不到文字、链接被访问边界阻止、参考文献段无法识别、图表编号位数过大等情况下，对应检查无法完成，需人工复核。

> 检查幻觉文献（编造或不存在的参考文献），推荐配合 [Paper-BibChecker](https://github.com/MLNLP-World/Paper-BibChecker) 对论文的 bib 文件进行核查。
